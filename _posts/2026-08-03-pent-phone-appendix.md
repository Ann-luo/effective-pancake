### 快速开始

1. 下载 `p-ent-phone.html`
2. 浏览器打开即可运行
3. 点 ⚙️ 设置 → 填入 [DeepSeek API Key](https://platform.deepseek.com/)
4. 点 💬 Phone 开始聊天

或使用 HBuilder X 打包为 Android APK（HTML5+）。

### 功能一览

- 🔒 锁屏 + 🏠 多页桌面 + 📌 Dock 栏 + 🧩 小组件 + 📂 文件夹
- 22 个 App + 7 个小游戏
- 💬 AI 聊天（多 Agent + 多房间）+ 💬 短信（AI 主动发信）
- 💾 一键备份恢复，数据完全本地
- 🎨 主题切换、🔍 全局搜索、🔔 通知系统

### 技术栈

纯前端 · 单文件 · 零依赖 · IndexedDB + localStorage · DeepSeek API · HBuilder HTML5+
