## 最终做出来的东西

| | |
|---|---|
| 访问地址 | `https://ob.<你的域名>`（全程 HTTPS，走 Cloudflare 隧道） |
| 记忆存哪 | 自己服务器上 `/opt/.../buckets-data/`，**一堆 `.md` 文件** |
| 公网开放端口 | **只剩 SSH**，服务端口一个都没开 |
| 服务端口绑定 | **只绑 `127.0.0.1`** —— 就算安全组被误开，外面也连不上（两层防线） |

| 备份 | GitHub 私有仓库，**每 24 小时自动**同步 |
| 防护 | fail2ban + 40 位随机 Token + HTTPS + 端口不暴露 |
| 成本 | 服务器 ¥99/年 + 域名约 ¥30/年；两个模型都极便宜或免费 |

## 全部踩过的坑（速查表）

**这张表是两篇里所有坑的合集 —— 遇到问题先在这儿找。**

| 报错 / 现象 | 看起来像 | 实际是 |
|---|---|---|
| `File has unexpected size ... Mirror sync in progress?` | 镜像源挂了 | **源正在同步**，换一个或等一会儿 |
| 换了源还是 `404 Not Found` | 包不存在 | **索引同步了、包还没同步完** |
| `registry-1.docker.io` 超时 | 网络坏了 | **国内直连 Docker Hub 本来就不通**，得配镜像源 |
| 镜像下到一半 8 秒只收 9KB | 镜像太大 | **镜像源掐了连接**，加超时重试能接着下 |
| 记忆全被标成「未分类」 | 打标模型太笨 | **`max_tokens` 太小 + 思考 token 吃掉预算** |
| Operit「连接」按钮灰着 | 输入格式不对 | **「名称」栏没填**（那个框在页面下面，要滚动） |
| Operit 报连接失败 | 网络/地址错 | 服务器日志显示 **`POST /` 打到了根路径**，URL 少 `/mcp` |
| `/mcp` 返回 401 | Token 过期 | **粘贴时断了一截**，开头少了几个字符 |
| Zero Trust 后台打不开 | 账号有问题 | **它要绑国际信用卡** → 换本地管理隧道 |
| `cloudflared login` 报 `Access is denied` | 没权限 | 它要写用户目录，**被环境限制挡**，改 `USERPROFILE` |
| 备份报「仓库不存在」 | 仓库名写错 | 可能只是**只填了仓库名、没填用户名** |
| 备份报**「分支 main 不存在」** | 分支真没了 | **报错在骗你** —— 真实原因是 token 看不见那个私有仓库 |
| token 明明"选了仓库" | 配置生效了 | **选择器点错成了别的仓库** |
| 仓库名跟预期不一样 | 自己记错了 | **建仓库时填的中文被 GitHub 静默剥掉了** |
| 改了端口绑定，`restart` 之后没变化 | 配置没生效 | **`restart` 不重建容器**，得 `up -d --force-recreate` |

## 如果你也想折腾，建议的顺序

⚠️ **一个前置提醒**：这套东西要花点钱（服务器 ¥99/年 + 域名约 ¥30/年），而且要有点耐心。

## 最后说两句

这一天做的东西不难，**难的是中间那些报错全都在指向错误的方向**：

- 说"仓库不存在" → 其实是没权限
- 说"分支不存在" → 其实还是没权限
- 说"连接失败" → 其实是 URL 少了路径
- 说"按钮点不动" → 其实是下面有个框没填

而且有两个坑是**我自己一开始就判断错的**：
- 我以为 DeepSeek 还有 `deepseek-chat` 这个模型 —— **用户当场纠正了我**
- 我看到"分支不存在"，第一反应是"那加个分支试试" —— **用户提议加分支，我去查了才发现报错本身在骗人**

**所以这一天的核心能力不是"会不会敲命令"，是"能不能看到真相"。**
而这一天从头到尾的救星只有一个：**服务器日志**。

手机上只告诉你"失败了"，服务器上写着"你打的是 `POST /`，我返回了 405"。
