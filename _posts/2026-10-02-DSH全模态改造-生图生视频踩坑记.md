## 0. 先说结论（懒人版）

想在 DSH 里白嫖生图和生视频，记住这五条：

1. **用 Agnes，不用别的**——它的 Flash 系列模型**当前免费**，而且注册不用信用卡、不用手机号。
2. **必须用国际站** `apihub.agnes-ai.com`。国内站 `api.agnes-ai.cn` 我用同一个 key 试了，**直接 401**。
3. **生图是同步的**（十几秒出结果），**生视频是异步的**（建任务 → 轮询 → 拿 URL），两者接口形态完全不同。
4. **生视频排队是常态**，不是你的 key 坏了。免费档视频队列长期满载，我实测**连续重试十次全撞队列满**。
5. **视频 URL 不会过期**——万一生成成功但没存下来，凭任务 ID 还能把 URL 查回来。这个救了我一次。

下面是完整过程，包括我怎么把 key 配错、怎么在队列里干等 14 分钟。

## 3. 第二步：验证 key 能不能用

拿到 key 别急着配到 DSH 里，**先单独验证一次**。这一步能帮你把"key 问题"和"配置问题"分开。

我用 Node.js 写了个小脚本（机器上装了 Node 就能跑）：

```javascript
// verify.js
const KEY = process.argv[2];
const BASES = [
  ['国内站', 'https://api.agnes-ai.cn/v1'],
  ['国际站', 'https://apihub.agnes-ai.com/v1'],
];

(async () => {
  for (const [name, base] of BASES) {
    console.log(`\n===== ${name}  ${base} =====`);
    try {
      const r = await fetch(`${base}/models`, {
        headers: { Authorization: `Bearer ${KEY}` },
      });
      const t = await r.text();
      console.log(`HTTP ${r.status}`);
      if (r.ok) {
        const j = JSON.parse(t);
        console.log(`共 ${j.data.length} 个模型:`);
        console.log(j.data.map(m => '  ' + m.id).join('\n'));
      } else {
        console.log(t.slice(0, 200));
      }
    } catch (e) {
      console.log('请求失败:', e.message);
    }
  }
})();
```

跑起来：

```powershell
node verify.js "你的key"
```

**结果非常有价值**：

```
===== 国内站  https://api.agnes-ai.cn/v1 =====
HTTP 401
{"error":{"message":"无效的令牌"}}

===== 国际站  https://apihub.agnes-ai.com/v1 =====
HTTP 200
共 12 个模型:
  agnes-3.0-flash
  agnes-2.5-flash
  agnes-image-2.5-flash
  agnes-video-2.5-flash
  ...
```

**关键发现：key 在国际站有效，国内站无效。** 这两个站的域名长得太像了，配错了会以为是 key 失效，白白浪费时间。

## 4. 第三步：写个脚本把生图和生视频包起来

DSH 支持任意 OpenAI 兼容 API，可以直接在「设置 → 模型」里配。但**生视频不是聊天模型能干的事**，得单独调接口。

所以我写了个脚本 `agnes.js`，把两个功能都封进去。核心就三个函数：

### 4.1 生图（同步接口）

```javascript
async function cmdImage(prompt, opt) {
  const r = await fetch('https://apihub.agnes-ai.com/v1/images/generations', {
    method: 'POST',
    headers: {
      Authorization: `Bearer ${KEY}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      model: 'agnes-image-2.5-flash',
      prompt: prompt,
      size: '1024x1024',
      extra_body: { response_format: 'url' },   // ← 注意这个
    }),
  });
  const j = await r.json();
  const url = j.data[0].url;      // 图片地址
  // 下载到本地就行
}
```

**生图很快**，我实测：

```
[生图] 模型=agnes-image-2.5-flash 尺寸=1024x1024
[生图] ✅ img-20261002-144948-1.png  (1168 KB)
[生图] 完成，耗时 19.4s
```

出来是一只挺像样的橘猫（光影、景深、毛发细节都在线）。

中文提示词直接用，不用翻译。我用的是"一只橘色小猫趴在窗台上晒太阳，写实摄影，浅景深"。

### 4.2 生视频（异步接口，麻烦得多）

生视频分两步，**不能一次拿到结果**：

```javascript
// 第一步：建任务
const created = await fetch('https://apihub.agnes-ai.com/v1/videos', {
  method: 'POST',
  headers: { Authorization: `Bearer ${KEY}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({
    model: 'agnes-video-2.5-flash',
    prompt: 'GBA 开机画面：像素风格掌机屏幕亮起...',
    seconds: '5',           // 4~12 秒
    mode: 'text',
    size: '720P',           // Flash 版固定 720P
    aspect_ratio: '16:9',
  }),
}).then(r => r.json());

const videoId = created.video_id;   // 记下这个

// 第二步：轮询（官方建议 5 秒一次）
while (true) {
  const q = await fetch(
    `https://apihub.agnes-ai.com/agnesapi?video_id=${videoId}&model_name=agnes-video-2.5-flash`,
    { headers: { Authorization: `Bearer ${KEY}` } }
  ).then(r => r.json());

  if (q.url) { /* 拿到视频了 */ break; }
  await new Promise(r => setTimeout(r, 5000));
}
```

> ⚠️ **查询必须带 `model_name`**。官方文档明确说了：**用 `task_id` 查会导致排队异常延长**。我一开始差点踩这个坑。
> 后来还发现 `GET /v1/videos/<id>` 也能查，返回更干净（URL 在 `metadata.url` 里）。

## 5. 第一坑：国内站和国际站是两个站

前面验证 key 的时候已经发现了，但值得单独说一遍，因为**这个坑太隐蔽**：

| 站点 | 地址 | 我的 key 的结果 |
|---|---|---|
| **国际站（用这个）** | `https://apihub.agnes-ai.com/v1` | ✅ 200，12 个模型 |
| 国内站 | `https://api.agnes-ai.cn/v1` | ❌ **401 无效的令牌** |

两个域名就差一个 `hub` 和 `.cn`/`.com`，配错了报的是"令牌无效"——**看起来特别像 key 的问题，其实是站选错了。**

我第一次看到 401 的时候还在想"是不是 key 复制多了空格"，试了三遍才发现是站点问题。

## 6. 第二坑：我第一次生视频，任务建不上

配好脚本，兴冲冲地跑第一次：

```
[生视频] 第 1 次建任务未成功 (HTTP 503: video_queue_full)，30s 后重试...
[生视频] 第 2 次建任务未成功 (HTTP 503: video_queue_full)，30s 后重试...
...
[生视频] 第 10 次建任务未成功 (HTTP 503: video_queue_full)，30s 后重试...
[错误] 多次重试仍无法创建视频任务
```

**十次全灭。**

我第一反应是"是不是我的 key 没权限"。于是做了个对照实验——**分别探测三个视频模型**：

```javascript
for (const m of ['agnes-video-2.5-flash', 'agnes-video-v2.0', 'agnes-video-2.5']) {
  // 各发一个请求看看返回什么
}
```

结果：

| 模型 | 返回 | 含义 |
|---|---|---|
| `agnes-video-2.5-flash` | `503 video_queue_full` | **服务端队列满** |
| `agnes-video-v2.0` | `429` 免费档限流 | 请求发太密 |
| `agnes-video-2.5` | `429` 免费档限流 | 同上 |

**结论：503 是队列满，跟我的 key、参数、脚本都没关系。** 而 429 更有意思——**我连着发三个探测请求，后两个立刻被限流**，说明免费档的限流非常紧。

> 💡 教训：**探测接口也要克制，别连着刷。** 我因为探测太密，反而污染了自己的测试结果。

## 7. 最大的坑：这个队列就没空过

搞清楚是队列问题后，我改进了脚本——**按错误类型区分退避时间**：

```javascript
const isQueueFull = r.status === 503 || (j && j.code === 'video_queue_full');
const isRateLimited = r.status === 429;
const wait = isRateLimited ? 90 : isQueueFull ? 60 : 30;   // 限流等更久
```

然后挂后台重试，最多等 45 分钟。

**过程是这样的**：

```
15:03:03 第 1/45 次未成功（队列满），已等 0.0 分钟，60s 后再试...
15:04:04 第 2/45 次未成功（队列满），已等 1.0 分钟，60s 后再试...
...
15:16:16 第 14/45 次未成功（队列满），已等 13.2 分钟，60s 后再试...
15:17:17 任务已创建 video_id=task_wCw8EIa5tXt5w0TYAtStwTrf64kpHGNS
15:18:xx #6  status=pending      已等待 0.6 分钟
15:21:xx #30 status=pending      已等待 3.0 分钟
15:21:xx #36 status=in_progress  已等待 3.6 分钟
15:21:xx #37 status=completed    已等待 3.7 分钟
```

**排队 14 分钟 + 生成 3.7 分钟 = 将近 18 分钟。**

就在我以为终于搞定的时候——

```
[错误] EPERM: operation not permitted, open 'D:\...\视频\video-20261002-152101.mp4'
```

**下载被沙箱拦了。** 因为我之前只授权了"图片"目录的写入权限，"视频"目录没授权。

> 顺带说一句：**产物要存哪儿是用户定的**——原话是"生图的文件别塞 C 盘，在桌面建个文件夹专门放"。所以输出目录改成了桌面上的 `DSH生成\`。用户的这个要求本身没问题，是我后来**新增 `视频\` 子目录时忘了这属于"新目录、要重新授权"**，才埋了这个雷。

### 救命的一招：URL 不会过期

好在视频生成成功时，URL 是打在日志里的。我抱着试试看的心态，**用任务 ID 重新查了一次**：

```javascript
const r = await fetch(
  `https://apihub.agnes-ai.com/agnesapi?video_id=task_wCw8EIa5...&model_name=agnes-video-2.5-flash`,
  { headers: { Authorization: `Bearer ${KEY}` } }
);
// 返回：{"status":"completed", "url":"https://platform-outputs.agnes-ai.space/videos/..."}
```

**URL 还在，任务记录没被清掉。** 直接下载下来：

```
HTTP 200 type=video/mp4 len=3337079
已写入: GBA开机画面-720P-5s.mp4 | 3.18 MB
```

**视频到手。**

我顺手把脚本也改了：以后生成成功**先把 URL 存到文件里**，再尝试下载。万一下载失败，也不至于白等一场。

## 8. 完整流程（直接抄）

如果你也想搞一套，按这个顺序来：

### 第一步：注册拿 key

1. 去 [platform.agnes-ai.com](https://platform.agnes-ai.com)
2. **优先用 Google / GitHub 授权登录**（邮箱注册可能遇到奇怪报错）
3. 控制台 → API Key → 创建 → **当场复制存好**

### 第二步：验证 key（别跳过）

用第 3 节那个 `verify.js`，确认**国际站返回 200**。

### 第三步：配脚本

脚本要点：

- **Base URL 用国际站** `https://apihub.agnes-ai.com`
- 生图：`POST /v1/images/generations`，**同步**，十几秒
- 生视频：`POST /v1/videos` 建任务 → `GET /agnesapi?video_id=xxx&model_name=xxx` 轮询
- **503 等 60 秒重试，429 等 90 秒重试**（别用同一个间隔）

### 第四步：接进 DSH

DSH 支持 OpenAI 兼容 API，在「设置 → 模型」里加自定义 provider 就行。但要注意——

**视频生成不是"聊天模型"能干的活**，得让 DSH 通过命令行调脚本。我是把它做成了一个 skill，以后直接说"生成个视频"就自动调用。

## 10. 几条实用建议

**关于生图：**
- 中文提示词直接能用，效果正常
- 想要特定画幅直接设 `--size`，别在提示词里描述尺寸
- 一般 12~20 秒出图，很快

**关于生视频：**
- **RPM = 1**，一分钟只能提交一个任务
- Flash 版**固定 720P**，传别的尺寸报 400；时长 **4~12 秒**
- **队列满了别硬等**——我实测连续 14 次都撞队列满。**换个时段**（比如早上）比挂着重试有效得多
- 生成成功了**立刻把 URL 存下来**，别等到下载失败才后悔

**关于安全：**
- key 是能花钱调用的凭证，**别贴到公开地方**
- 我把 key 放在配置文件的独立位置，分享工作区或截图前会先检查

## 11. 最后说两句

回头看，**真正花时间的不是"接 API"，而是搞明白各种失败返回的区别**：

- 401 = 站点选错了（不是 key 坏了）
- 403 = 视频 URL 对方不让访问
- 429 = 你请求发太密了
- 500 = 可能是文件太大，也可能是服务端抽风
- 503 + `video_queue_full` = **服务端排队，跟你没关系**

**能分清这几种，能省掉一大半瞎折腾。**

至于"能力扩大 5~6 倍"这种说法——**生图生视频确实好用，但别为了凑数去接一堆用不上的东西。** 我到现在联网搜索都没怎么用，因为日常够用了。
